# Импорт цен Медиалог

Windows-приложение для загрузки цен услуг из Excel (`.xlsx`) в Microsoft SQL Server, используемый Медиалогом. Подключение к БД выполняется через ODBC с помощью `dart_odbc: ^6.2.0`.

> **Состояние проекта:** стартовая рабочая версия (MVP-каркас) с экраном подключения, чтением и проверкой листов Excel, настройками параметров по умолчанию, алгоритмом INSERT/UPDATE и журналом операций. Перед эксплуатацией на рабочей базе обязательно выполните проверку на копии БД и подтвердите реальные поля кодов услуги в вашей версии Медиалог.

## Возможности

- Подключение к MSSQL через установленный ODBC-драйвер.
- Окно подключения показывается при первом запуске или при ошибке соединения.
- Настройки приложения сохраняются в `app_settings.json` рядом с исполняемым файлом.
- Выбор Excel-файла формата `.xlsx`.
- Отображение всех листов, количества непустых строк данных и результата проверки.
- Обязательные заголовки: `FM_SERV_CODE`, `PRICE`.
- Дополнительные заголовки: `DATE_FROM`, `FM_DEVISE_CODE`, `FM_PRICETYPE_CODE`, `FM_PRICE_CATEGORY_CODE`.
- Общие значения по умолчанию для всего импорта. Значение в ячейке Excel имеет приоритет над значением по умолчанию.
- Поиск услуги и значений справочников в Медиалог.
- Поиск цены по услуге, дате без времени, типу цены, категории и валюте.
- Обновление найденной цены или создание новой записи.
- Журнал с фильтрами «Ошибки», «Успешно», «Все».

## Требования

1. Windows 10/11 x64.
2. Flutter SDK с поддержкой Windows Desktop.
3. Visual Studio 2022 с workload **Desktop development with C++**.
4. Microsoft SQL Server ODBC Driver (например, ODBC Driver 18 for SQL Server) той же разрядности, что и приложение.
5. Доступ к базе Медиалог и права `SELECT`, `INSERT`, `UPDATE` на используемые таблицы.

Проверьте наличие драйвера: откройте меню Пуск и найдите **Источники данных ODBC (64-разрядная версия)**, затем вкладку **Драйверы**. В поле «Имя ODBC-драйвера» в приложении укажите точное имя из этого списка, например `ODBC Driver 18 for SQL Server`.

## Настройка подключения

В окне подключения задаются:

- Сервер: `SERVER` или `SERVER\INSTANCE`.
- Порт: обычно `1433`; для именованного экземпляра при необходимости оставьте порт пустым и используйте `SERVER\INSTANCE`.
- База данных: имя БД Медиалог.
- Имя ODBC-драйвера: точное имя установленного драйвера.
- Авторизация Windows или SQL Server (логин/пароль).

Приложение выполняет тестовый `SELECT 1`. При успешном соединении настройки сохраняются в `app_settings.json` рядом с `.exe`.

### Важное замечание о защите пароля

В этой стартовой версии `app_settings.json` содержит пароль подключения в открытом виде. Не размещайте приложение и этот файл в общедоступном каталоге, не отправляйте файл настроек третьим лицам и ограничьте права доступа к папке средствами Windows. Для промышленной эксплуатации следующим обязательным шагом должна стать защита секрета через Windows DPAPI / Credential Manager. Не используйте один общий SQL-логин с избыточными правами.

Если приложение находится в `Program Files`, у обычного пользователя может не быть права записывать настройки рядом с `.exe`. Для первого запуска используйте отдельный каталог приложения с правами записи либо настройте ACL папки.

## Формат Excel

Первая строка каждого листа должна содержать заголовки колонок. Регистр заголовков не важен, пробелы по краям удаляются.

| Колонка | Обязательность | Назначение |
|---|---|---|
| `FM_SERV_CODE` | Да | Код услуги |
| `PRICE` | Да | Цена |
| `DATE_FROM` | Нет* | Дата начала действия цены |
| `FM_DEVISE_CODE` | Нет | Код валюты |
| `FM_PRICETYPE_CODE` | Нет* | Код типа цены |
| `FM_PRICE_CATEGORY_CODE` | Нет | Код категории цены |

`*` Дата и тип цены обязательны для фактической записи в `FM_SERVPRICE`. Если значения отсутствуют в строке Excel, используются значения по умолчанию из настроек импорта. Если итоговое значение не определено, строка попадёт в журнал ошибок.

Допустимые даты: `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`; Excel-ячейки с типом даты также поддерживаются. Цена обрабатывается как десятичное значение с точкой или запятой и максимум четырьмя знаками после разделителя.

Лист без обязательных заголовков не может быть выбран для импорта. Пустые строки пропускаются.

## Алгоритм сопоставления с БД

### Услуга

В текущем варианте выполняется поиск:

```sql
SELECT TOP 1 FM_SERV_ID
FROM FM_SERV
WHERE FM_SERV_CODE = ?
```

Если запись не найдена, строка фиксируется как ошибка. В исходных требованиях упомянуты также код Минздрава и код ОМС, но конкретные имена соответствующих колонок таблицы `FM_SERV` пока не предоставлены. Поэтому поиск по этим двум альтернативным кодам **ещё не реализован**. После получения точных имён колонок алгоритм нужно расширить.

### Тип цены, валюта и категория

- `FM_PRICETYPE.FM_PRICETYPE_CODE` → `FM_PRICETYPE_ID`.
- `FM_DEVISE.FM_DEVISE_CODE` → `FM_DEVISE_ID`.
- `FM_PRICE_CATEGORY.FM_PRICE_CATEGORY_CODE` → `FM_PRICE_CATEGORY_ID`.

Тип цены обязателен для вставки, так как `FM_PRICETYPE_ID` в `FM_SERVPRICE` обязательный. Валюта и категория могут быть `NULL`, если они не заданы ни в строке, ни в настройках. Если код задан, но отсутствует в соответствующем справочнике, строка завершается ошибкой.

### Поиск существующей цены

Сопоставление выполняется по:

1. `FM_SERV_ID`.
2. `DATE_FROM` с приведением к типу `date` (время игнорируется).
3. `FM_PRICETYPE_ID`.
4. `FM_PRICE_CATEGORY_ID`, включая корректное сравнение `NULL`.
5. `FM_DEVISE_ID`, включая корректное сравнение `NULL`.

Если цена найдена, обновляется `PRICE`. Если нет — создаётся запись в `FM_SERVPRICE`. `FM_CONTR_ID` и `MAXCNT` не заполняются.

Каждая строка обрабатывается отдельно в транзакции. Ошибка одной строки не должна останавливать обработку следующих строк.

## Проверочный сценарий перед рабочим импортом

1. Сделайте резервную копию базы или используйте тестовую базу.
2. Подготовьте Excel с 2–3 строками: одна существующая услуга, одна новая цена, один заведомо неверный код услуги.
3. Сначала проверьте подключение и анализ листов.
4. Установите дату и тип цены по умолчанию, если они не указаны в Excel.
5. Выполните импорт и проверьте журнал.
6. Сверьте созданные и обновлённые строки непосредственно в `FM_SERVPRICE`.
7. Отдельно проверьте варианты с пустой валютой/категорией и с датами, у которых в исходных данных есть время.

## Известные ограничения стартовой версии

- Поддерживается `.xlsx`; старый формат `.xls` не поддерживается.
- Поиск услуги пока реализован только по `FM_SERV_CODE`, так как названия колонок кодов Минздрава и ОМС не указаны.
- Пароль в конфигурации пока не зашифрован (см. раздел о защите пароля).
- Для production-развёртывания нужно проверить фактическую схему и типы полей конкретной базы Медиалог, а также протестировать поведение ODBC-драйвера на целевой версии SQL Server.
- Текущий интерфейс — MVP; экспорт журнала и отмена уже начатого импорта пока не реализованы.
