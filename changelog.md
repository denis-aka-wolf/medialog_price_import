## [1.2.0] - 2026-11-05 (bdce7cc)
* Добавлен функционал полноценного логирования

### Added
- Добавлено расширенное системное логирование приложения.
- Добавлена запись ошибок подключения к Microsoft SQL Server через ODBC.
- Добавлено логирование выполнения SQL-запросов и SQL-команд.
- Добавлено логирование ошибок обработки отдельных строк Excel.
- Добавлено сохранение StackTrace для исключений, упрощающих поиск причин ошибок.
- Добавлено логирование операций открытия, анализа и чтения Excel-файлов.
- Добавлено логирование загрузки и сохранения настроек приложения.
- Добавлены глобальные обработчики необработанных ошибок Flutter и Dart.
- Добавлено логирование начала и завершения импорта с указанием количества успешно обработанных записей и ошибок.
- Добавлено логирование ошибок отката транзакций.
- Добавлено сохранение диагностических журналов в каталог `logs` рядом с исполняемым файлом.
- Добавлена ежедневная организация логов по отдельным файлам.
- Добавлен контекст ошибок: имя листа, номер строки Excel, код услуги и параметры операции.

### Changed
- Централизовано логирование ошибок во всех основных компонентах приложения.
- Расширена диагностическая информация при подключении к базе данных.
- Улучшена диагностика проблем при импорте Excel.
- Улучшена обработка ошибок чтения и сохранения настроек.
- Обновлена документация README.md с описанием системы логирования и расположения журналов.

### Fixed
- Исправлено отсутствие записи ошибок подключения к MSSQL в системный журнал.
- Исправлена потеря диагностической информации при обработке ошибочных строк Excel.
- Исправлено отсутствие StackTrace для ряда исключений.
- Устранено молчаливое игнорирование некоторых ошибок чтения конфигурации.
- Улучшена фиксация ошибок при выполнении SQL-команд и транзакций.
- Добавлена диагностика необработанных исключений, которые ранее могли оставаться вне локальных обработчиков.

### Security
- Исключены логин и пароль базы данных из диагностического контекста подключения.
- Добавлено предупреждение о том, что SQL-запросы могут содержать рабочие данные, включая коды услуг и цены.

### Documentation
- Обновлена документация проекта.
- Добавлено описание структуры каталогов с логами.
- Добавлено описание состава диагностической информации.
